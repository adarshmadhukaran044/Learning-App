## SkillNest – Project Summary

SkillNest is a modern and interactive e-learning web application developed using HTML, CSS, and JavaScript. The project is designed to provide users with a complete online learning experience where they can explore courses, track progress, watch lessons, and manage their learning journey through a visually attractive and responsive interface. The application delivers a professional user experience while remaining fully browser-based without requiring any backend server or database.
The structure of the project is divided into three main files. The HTML file creates the overall structure of the application, including the login page, navigation rail, dashboard, course sections, progress tracking area, and video learning page. It contains multiple interactive sections such as authentication forms, course cards, search filters, and user profile components that organize the entire platform in a clean and user-friendly layout.

## What Technologies Are Used?
This project uses three main files, each performing a different role:
HTML (index.html) — The HTML file creates the complete structure of the application. It contains the login system, navigation rail, dashboard, course sections, progress area, search filters, account settings, and video learning interface. HTML acts as the foundation of the platform and organizes all visible components on the screen.
CSS (style.css) — The CSS file handles the design and appearance of the application. It creates the elegant layout, color themes, animations, shadows, gradients, responsive cards, buttons, and dark mode functionality using a deep dark theme with electric teal accents. The styling gives SkillNest a premium and editorial look built around Space Mono, Bebas Neue, and DM Sans typography.
JavaScript (app.js) — JavaScript controls all dynamic features of the application. It manages course data, page navigation, filtering systems, user interactions, lesson progress, course rendering, and application logic. JavaScript acts as the brain of SkillNest and makes the platform fully interactive and functional.

## How Does the Application Work?
When the application starts, users first see a login and registration page where they can sign in, register, or continue as a guest. After logging in, the user enters the main dashboard, which displays personalised information such as learning streaks, XP progress, enrolled courses, certificates, and recommended learning paths.
The dashboard allows users to continue unfinished lessons and explore new courses from different categories including development, design, marketing, finance, and AI. Each course contains lesson sections, ratings, instructors, progress tracking, and pricing information stored dynamically in JavaScript objects. Users can search and filter courses by category, rating, and price. Clicking a course opens the video learning page where lessons, playlists, and course progression are displayed. The application also includes a dark and light mode toggle for accessibility.

## What Features Does It Have?
Modern Login and Registration System — Users can sign in, create accounts, or continue as guests. Interactive Dashboard — Displays learning streaks, XP points, progress tracking, and enrolled courses. Large Course Collection — Includes multiple categories such as UI/UX, Python, React, Marketing, Finance, and AI. Course Search and Filters — Users can search and sort courses by category, rating, and price. Progress Tracking System — Shows completed lessons, course percentages, activity heatmaps, and achievements. Responsive Design — Works smoothly on desktop, tablet, and mobile devices. Dark and Light Mode — Users can switch themes at any time. Professional UI/UX Design — Uses editorial typography, teal accent gradients, animated cards, and a compact icon rail for a premium experience.

## Summary
SkillNest is a complete and visually distinctive e-learning platform developed using HTML, CSS, and JavaScript. It provides users with an engaging learning experience through interactive dashboards, course management systems, responsive layouts, and dynamic functionality. The project demonstrates strong frontend development skills and serves as an excellent portfolio example of how modern educational platforms can be built using core web technologies alone.
